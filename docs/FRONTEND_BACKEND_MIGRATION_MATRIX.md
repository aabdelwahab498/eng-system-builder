### Migration Status Legend

- **VERIFIED**: Checked against frontend code and documented.
- **PLANNED**: Endpoint contract defined, ready for implementation.
- **IMPLEMENTED**: Endpoint exists, tested, and integrated with frontend content adapter.
- **MIGRATED**: Frontend adapter updated to use backend endpoint.
- **DEPRECATED**: Replaced or obsolete.
- **UNKNOWN**: Under investigation.
